# موقع حسن — مونتير ريلز سينمائية

- الموقع: **https://h2ssanali.github.io/**
- الاستوديو (لوحة التعديل، بتشتغل منيح ع الجوال): **https://h2ssanali.github.io/studio/**

كل التعديلات بتصير من **الاستوديو**، بدون أي كود. الاستوديو فيه ٤ تبويبات تحت: **أعمالي · الشكل · معلوماتي · معاينة**.

---

## ١. إضافة رقمك وحساباتك

1. افتح الاستوديو واضغط **معلوماتي**.
2. تحت «رقمي وحساباتي» عبّي اللي بدك ياه:
   - **واتساب:** الرقم مع رمز الدولة، بدون + وبدون صفر بالأول (مثلاً `9665xxxxxxxx`).
   - **إنستغرام، تيك توك، يوتيوب، سناب شات، إكس:** اكتب اسم الحساب بس (مثلاً `@hassan`)، أو الصق الرابط كامل.
   - **الإيميل.**
3. اضغط **نشر التعديلات** (شوف الخطوة ٥).

كل خانة بتعبّيها بتطلع زر بقسم «خلّينا نعمل ريلك الجاي» آخر الموقع، والفاضية ما بتطلع.

## ٢. تغيير ستايل الموقع

1. بالاستوديو اضغط **الشكل**.
2. اختار واحد من الستايلات الأربعة، وبتشوف النتيجة فوراً بتبويب **معاينة**:
   - **غرفة المونتاج:** ليل وضوء كهرماني.
   - **أرشيف ورقي:** ورق قديم وحبر وختم أحمر.
   - **أبيض وأسود:** الصور بالأبيض والأسود وبتتلوّن لما تلمسها.
   - **تيل وبرتقالي:** ألوان التصحيح السينمائي المشهورة.
3. اضغط **نشر التعديلات**.

بدك تشوف أي ستايل على الموقع الحقيقي قبل ما تختار؟ افتح الرابط وزيد عليه اسم الستايل:
`?theme=suite` · `?theme=archive` · `?theme=noir` · `?theme=teal`
(مثلاً: https://h2ssanali.github.io/?theme=archive)

## ٣. الأعمال: العناوين، الترتيب، الشوريل

- اضغط على أي عمل لتغيّر **العنوان** و**التصنيف** و**سطر الوصف**.
- **★** بيحط العمل بالشوريل فوق (الأحلى من ٤ لـ ٦ أعمال).
- **👁** بيخفي العمل من الموقع بدون ما ينحذف.
- **↑ ↓** لتغيير الترتيب، أو اسحب من **⋮⋮**.
- **التصنيفات:** تحت القائمة، بتقدر تضيف تصنيف جديد أو تغيّر اسم واحد موجود، والاسم الجديد بيتغيّر بكل الأعمال.

## ٤. إضافة فيديو جديد

1. افتح https://github.com/h2ssanali/h2ssanali.github.io/upload/main/incoming (أو من الاستوديو: زر **رفع فيديو**).
2. اسحب ملف الفيديو (MP4 أو MOV) وأفلته، واضغط **Commit changes**.
3. خلال ٣ لـ ١٠ دقائق بيطلع بالاستوديو بعنوان مؤقت. غيّر العنوان والتصنيف وانشر.

> رفع الملفات من موقع GitHub بيقبل لحد **25 ميغا**. إذا الفيديو أكبر صدّره بجودة أقل، أو ارفعه من تطبيق GitHub Desktop (لحد 100 ميغا).

## ٥. نشر التعديلات (زر واحد)

1. بعد ما تخلص اضغط **نشر التعديلات** (الزر البرتقالي تحت).
2. اضغط **افتح GitHub**. بتنفتح صفحة وتعديلاتك جاهزة فيها.
3. اضغط الزر الأخضر **Commit changes…** ثم **Commit changes** مرة ثانية.
4. خلال دقيقة أو دقيقتين بيتحدّث الموقع.

لازم تكون داخل على GitHub بحسابك. الاستوديو ما بيحفظ أي كلمة سر، وتعديلاتك اللي ما نشرتها بتضل محفوظة على جهازك بس.
وإذا يوم ما زبطت الطريقة، بنفس النافذة في **طريقة النسخ واللصق** كخطة بديلة.

---

## مين بيقدر يعدّل الموقع؟

بس إنت. المستودع عام (أي حدا بيقدر يشوف الكود)، بس النشر بيحتاج حساب GitHub إله صلاحية، وهو حسابك بس. ننصحك تفعّل التحقق بخطوتين: GitHub ← Settings ← Password and authentication.

## للمطوّرين

| المسار | ماذا فيه |
|---|---|
| `index.html`, `assets/` | الموقع (HTML/CSS/JS بدون framework وبدون build). الستايلات الأربعة كلها متغيّرات CSS في `assets/css/site.css` |
| `studio/` | الاستوديو |
| `content.json` | كل المحتوى: `site` (النصوص والتواصل و`theme`)، `categories`، `style` (لقطات «أسلوبي»)، `works` |
| `media/` | الفيديوهات المضغوطة والمقاطع القصيرة والأغلفة، و`media/style/` للقطات «أسلوبي» |
| `incoming/` | فيديو جديد ← `add-work.yml`. تعديل من الاستوديو (`*.studio`) ← `apply-studio.yml` |
| `scripts/process.py` | معالجة فيديو: H.264 بمقاس 720×1280، CRF 26، AAC، faststart، مع غلاف ومقطع معاينة |
| `scripts/apply_studio.py` | يدمج تعديل الاستوديو في `content.json` ويثبّت الستايل في `index.html` |
| `scripts/import.sh` | استيراد مجلدات Google Drive (تبويب Actions ← Import from Google Drive) |
