# موقع حسن — مونتير ريلز سينمائية

الموقع: **https://h2ssanali.github.io/**
الاستوديو (لوحة التعديل المخفية): **https://h2ssanali.github.io/studio/**

كل محتوى الموقع موجود في ملف واحد اسمه **`content.json`**. لا تحتاج أن تكتب كوداً.
أسهل طريقة للتعديل هي **الاستوديو**. وإذا أحببت تعديل الملف بيدك، تجد شرحه بالتفصيل في آخر هذه الصفحة.

---

## ١. إضافة عمل جديد (فيديو جديد)

1. افتح صفحة المستودع على GitHub: https://github.com/h2ssanali/h2ssanali.github.io
2. ادخل مجلد **`incoming`**.
3. اضغط **Add file** ثم **Upload files**.
4. اسحب ملف الفيديو (MP4 أو MOV) وأفلته في الصفحة.
5. اضغط الزر الأخضر **Commit changes**.

بعدها يعمل GitHub وحده (تقريباً من ٣ إلى ١٠ دقائق):
- يضغط الفيديو للويب بمقاس 720×1280 (9:16).
- يختار أقوى لقطة ليجعلها صورة الغلاف.
- يصنع مقطعاً قصيراً صامتاً يتحرك عند المرور على البطاقة.
- ينقل كل شيء إلى مجلد `media/`، ويضيف العمل إلى `content.json` بعنوان مؤقت (اسم الملف).

يمكنك متابعة التقدّم من تبويب **Actions** في المستودع. حين تظهر علامة ✓ خضراء، افتح **الاستوديو** وغيّر العنوان والتصنيف (انظر الخطوة ٢).

> **تنبيه:** موقع GitHub يقبل ملفات حتى **25 ميغابايت** عند الرفع من المتصفح. إذا كان الفيديو أكبر، صدّره بجودة أقل أولاً (مثلاً 1080p بمعدّل 8 Mbps)، أو ارفعه عبر تطبيق GitHub Desktop (يقبل حتى 100 ميغابايت).

> **فيديو "قبل وبعد":** ارفع النسختين (الخام والنهائية). بعدها في الاستوديو افتح **تفاصيل** في العمل النهائي، واختر النسخة الخام في خانة **فيديو "قبل"**. وإن أردت ألا تظهر النسخة الخام كعمل مستقل، اضغط 👁 لإخفائها.

---

## ٢. تغيير العناوين والتصنيفات والنصوص (عبر الاستوديو)

1. افتح **https://h2ssanali.github.io/studio/**
2. عدّل ما تريد، وكل تعديل يظهر مباشرة في المعاينة:
   - **العنوان:** اكتب في خانة العنوان.
   - **التصنيف:** اختره من القائمة.
   - **★ مميّز:** يجعل العمل يظهر في الشوريل أعلى الصفحة (الأفضل من ٤ إلى ٦ أعمال).
   - **👁 إخفاء:** يخفي العمل من الموقع دون أن يحذفه.
   - **تفاصيل:** فيها سطر وصف قصير يظهر داخل المشغّل، وخانة فيديو "قبل".
   - **معلومات الموقع:** الاسم، الجملة الرئيسية، النبذة، وروابط إنستغرام والبريد وواتساب. أي خانة تتركها فارغة لا تظهر في الموقع.
3. حين تنتهي اضغط **نسخ المحتوى ↗**. سيُنسخ المحتوى الجديد وتُفتح صفحة تعديل `content.json` على GitHub.
4. في صفحة GitHub: اضغط داخل المحرّر، ثم حدّد الكل (**Ctrl+A** أو **⌘A**)، ثم الصق (**Ctrl+V** أو **⌘V**).
5. اضغط **Commit changes** ثم أكّد. خلال دقيقة أو دقيقتين يتحدّث الموقع.

> الاستوديو لا يحتاج كلمة سر، ولا يحفظ أي بيانات دخول. التعديلات التي لم تنشرها تبقى محفوظة في متصفحك فقط، حتى تنشرها أو تضغط **استرجاع المنشور**.

---

## ٣. تغيير ترتيب الأعمال

في الاستوديو، اسحب العمل من المقبض **⋮⋮** (على يمين البطاقة) إلى المكان الذي تريده. على الجوال يمكنك أيضاً فتح **تفاصيل** واستعمال الأسهم ↑ ↓.
الترتيب في الاستوديو هو نفسه ترتيب الأعمال في الموقع. بعد الانتهاء اتبع الخطوات ٣ إلى ٥ من القسم السابق.

---

## ٤. إضافة تصنيف جديد

1. في الاستوديو افتح قسم **التصنيفات**.
2. اكتب اسم التصنيف في الخانة الأخيرة واضغط **إضافة**.
3. اذهب إلى الأعمال واختر هذا التصنيف للأعمال المناسبة.
4. انشر كالعادة: **نسخ المحتوى** ثم لصق ثم **Commit changes**.

ملاحظات:
- تغيير اسم تصنيف يحدّثه تلقائياً في كل الأعمال التي تحمله.
- أي تصنيف ليس فيه أعمال لا يظهر في الموقع.
- ترتيب التصنيفات في الاستوديو هو ترتيب الأزرار في الموقع.

## ٥. شرح ملف `content.json` (لمن يريد التعديل بيده)

```jsonc
{
  "site": {
    "name": "حسن",                 // الاسم الكبير في أعلى الصفحة
    "name_latin": "HASSAN",        // تفصيل صغير بالإنجليزي
    "role": "مونتير ريلز سينمائية", // الوصف المهني
    "tagline": "…",                // الجملة الرئيسية تحت الاسم
    "about": "…",                  // نص قسم «نبذة»
    "instagram": "",               // اسم الحساب أو الرابط. اتركه "" لإخفاء الزر
    "email": "",                   // البريد. اتركه "" لإخفاء الزر
    "whatsapp": "",                // الرقم مع رمز الدولة بدون +، مثل 9665xxxxxxxx
    "og_image": "assets/og.jpg"    // الصورة التي تظهر عند مشاركة الرابط
  },
  "categories": ["حكايات من التاريخ", "شخصيات"],  // التصنيفات بالترتيب
  "works": [                       // الأعمال بالترتيب الذي تظهر به
    {
      "id": "w1a2b3c4",            // معرّف ثابت. لا تغيّره
      "title": "سقوط القسطنطينية",  // العنوان
      "category": "حروب ومعارك",    // لازم يطابق اسماً من categories
      "blurb": "",                 // سطر اختياري يظهر في المشغّل
      "video": "media/w1a2b3c4.mp4",         // الفيديو الكامل
      "poster": "media/w1a2b3c4.webp",       // صورة الغلاف
      "preview": "media/w1a2b3c4-loop.mp4",  // المقطع الصامت القصير
      "duration": 58.2,            // المدة بالثواني (تُكتب تلقائياً)
      "featured": true,            // true = يظهر في الشوريل
      "hidden": false,             // true = مخفي من الموقع
      "before": ""                 // مسار فيديو «قبل» لقسم قبل/بعد (اختياري)
    }
  ]
}
```

انتبه لهذه القواعد عند التعديل باليد: الفواصل `,` بين العناصر، وعلامات التنصيص `" "` حول كل نص، وعدم وجود فاصلة بعد آخر عنصر. وإذا لم تكن متأكداً، استعمل الاستوديو.

## للمطوّرين: الملفات والأدوات

| المسار | ماذا فيه |
|---|---|
| `index.html`, `assets/` | الموقع (HTML/CSS/JS بدون أي framework وبدون خطوة build) |
| `studio/` | الاستوديو |
| `content.json` | كل المحتوى |
| `media/` | الفيديوهات المضغوطة، المقاطع القصيرة، وصور الغلاف |
| `incoming/` | ضع هنا فيديو جديداً وسيعالجه GitHub Actions |
| `curation/` | لقطات وتفريغ صوتي لكل فيديو (يساعد في اختيار العناوين، ولا يظهر في الموقع) |
| `scripts/import.sh` | استيراد مجلدات Google Drive ثم الضغط وصناعة الأغلفة والمقاطع |
| `scripts/process.py` | معالجة أي فيديو: ‏H.264 بمقاس 720×1280 و CRF 26 و AAC و faststart |
| `.github/workflows/add-work.yml` | يعالج ما يُرفع إلى `incoming/` |
| `.github/workflows/import-drive.yml` | استيراد كامل من Drive (من تبويب Actions ثم Run workflow) |

تشغيل الاستيراد على جهازك (يحتاج python3 و ffmpeg):

```bash
scripts/import.sh "https://drive.google.com/drive/folders/<ID>"
```

مجلدات Drive لازم تكون مشاركة بإعداد **Anyone with the link**.
